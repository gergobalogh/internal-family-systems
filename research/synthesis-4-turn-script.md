# Synthesis — 4-turn entry question script (Briefs 1→3)

Date: 2026-10-12. Inputs: [brief1-ifs-elicitation.md](brief1-ifs-elicitation.md),
[Brief 2 report](../docs/deep-research-2-report.md) (+ §8 verification),
[brief3-uncertainty-transition.md](brief3-uncertainty-transition.md).

Global rules (all turns): reflection first, then ONE focused question; hedges
match confidence ("it sounds like…", "one way to see this…"); every
interpretation is an editable hypothesis with an easy correction path; tag
all attributes current-state unless explicitly imagining change; never
villainize a part; short turns (verbosity inflates false confidence); fused identify+name questions permitted (Turns 1, 4a): the name slot must resolve to user words or an explicit no/unsure — never inferred. All other fused forms stay banned.

## The script

**Turn 0 — Free-write (no question).** "In your own words, what's weighing
on you right now? No need to be organized." (B1: labeling + disclosure do
work before any question.) Render: blank calm field.

**Turn 1 — Identity + influence (B1 opener 1 + B2 T1 merged).**
Reflect one line in parts language, then ask: *"Which feeling has been
loudest lately — what would you call it?"* Yields: user-named part +
size/volume seed ("loudest" → largest). Render: first faint trace at scale.

**Turn 2 — Toward-check (B1 opener 2).** *"And how do you feel toward
[their name] — curious about it, frustrated with it, or something else?"*
Yields: Self-energy probe + polarization detection. If warmth/curiosity →
proceed. If hate/can't-stand-it → a SECOND part is speaking; name it
("sounds like another part has strong feelings about this one") and note a
tension link for Turn 4. Render: trace sharpens; second trace if polarized.

**Turn 3 — Centrality (B2 T2).** *"Does [name] feel close, or more off to
the side?"* (Optional follow-up only if vague: "How far does it feel right
now?") Yields: distance-from-centre per part. Render: positions settle.

**Turn 4 — Unheard + whole-map confirmation (B2 T4 + B3 phrasing).**
*"Is there a part that rarely gets heard — what would you call it?"* (a bare "yes" gets one naming follow-up, "What would you call it?"; no-forms mean none, unsure-forms mean unsure) then confirm the map as a
candidate: *"One way I'm seeing this is [map in their words] — what would
you change?"* The tension link from any Turn 2 polarization branch rides
inside the confirmed map, not as a separate question. Allied/silenced
links, if still unobserved, are explored post-visualization — never as
conditional extra questions here. Render: faint trace for the unheard part;
landscape comes into focus.

**Post-visualization — first experiment (B3, only if earned).** Invite only
when all four hold: preparatory change talk observed, no sustain-talk
dominance, one correction loop completed, 2+ parts in user's words. Use the
EPE template in the "What if" thread with instant undo. Otherwise stay
Mirror.

## Deliberate deviations from Brief 2's plan

- Brief 2's Turn 1 ("loudest… what does it keep saying?") merged with
  Brief 1's naming opener: naming must precede quoting, and "loudest"
  already seeds influence. Voice-quoting moves to post-visualization
  exploration.
- The toward-check (Turn 2) displaces nothing: relationships shift from
  Turn 3 to Turn 4 confirmation because the polarization branch yields the
  tension link for free in the common two-part case. Allied/silenced links
  still unobserved at Turn 4 are deferred to post-visualization rather than
  asked conditionally, capping Turn 4 at two questions except the bare-yes path, where a naming follow-up is the only alternative to inventing a name.
- Brief 2's "has that shifted lately?" temporal alternative is dropped for
  v1: no empirical comparison exists (Brief 2 §7), and four turns are full.

## Correction handling (any turn)

"Thanks — fixing that: [corrected]. Anything else off?" Update the visible
map immediately; never defend the old reading; record the source phrase so
re-inference can't resurrect it. Rejected part → remove + confirm removal.
